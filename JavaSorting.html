Mastering Java Array Sorting

Definitions, Concepts, Algorithm Comparison Table, and Complete Runnable Code

1. Introduction & Key Terminology

When we talk about sorting an array in Java, we are rearranging the elements stored in contiguous heap memory into a strict sequence (ascending or descending). To understand sorting deeply, let's establish core definitions:

What is Sorting? The algorithmic process of organizing elements by comparing their values and repositioning them relative to one another.
What is a Swap? Because array elements cannot magically move past each other in memory, sorting requires temporarily holding a value in a variable so two slots can exchange contents:
int temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;
What is Time Complexity (Big-O)? A mathematical notation describing how execution time scales as the array size ($n$) grows.
  • O(n) - Linear Time: Execution scales directly and efficiently with size.
  • O(n²) - Quadratic Time: Requires nested loops (comparing every element against every other element). Typical for simple sorting algorithms.
  • O(n log n) - Log-Linear Time: Highly optimized divide-and-conquer efficiency.

2. Bubble Sort

Definition: Bubble Sort is a straightforward sorting algorithm that repeatedly steps through the array, compares adjacent elements, and swaps them if they are in the wrong order.

How it works conceptually: Imagine heavy numbers sinking to the bottom while light numbers "bubble" up to the top. In each full pass through the array, the largest unsorted element bubbles up to its final correct position on the far right.

Complete Runnable Example: Bubble Sort

BubbleSortMaster.java 
public class BubbleSortMaster {
    public static void main(String[] args) {
        int[] numbers = {64, 34, 25, 12, 22, 11, 90};

        System.out.println("--- Before Bubble Sort ---");
        printArray(numbers);

        // Outer loop controls the number of passes
        for (int i = 0; i < numbers.length - 1; i++) {
            boolean swapped = false;

            // Inner loop performs adjacent comparisons
            for (int j = 0; j < numbers.length - i - 1; j++) {
                // If left element is greater than right, swap them
                if (numbers[j] > numbers[j + 1]) {
                    int temp = numbers[j];
                    numbers[j] = numbers[j + 1];
                    numbers[j + 1] = temp;
                    swapped = true;
                }
            }

            // Optimization: if no swaps occurred, array is already sorted!
            if (!swapped) {
                break;
            }
        }

        System.out.println("--- After Bubble Sort ---");
        printArray(numbers);
    }

    public static void printArray(int[] arr) {
        for (int n : arr) {
            System.out.print(n + " ");
        }
        System.out.println();
    }
}

3. Selection Sort

Definition: Selection Sort divides the array into two regions: a sorted region on the left and an unsorted region on the right. It repeatedly scans the unsorted region to find the minimum value, then swaps it into the next available spot in the sorted region.

Complete Runnable Example: Selection Sort

SelectionSortMaster.java 
public class SelectionSortMaster {
    public static void main(String[] args) {
        int[] scores = {85, 42, 99, 58, 71};

        System.out.println("--- Before Selection Sort ---");
        printArray(scores);

        for (int i = 0; i < scores.length - 1; i++) {
            // Assume the first element of the unsorted region is the minimum
            int minIndex = i;

            // Scan the rest of the array to find a smaller element
            for (int j = i + 1; j < scores.length; j++) {
                if (scores[j] < scores[minIndex]) {
                    minIndex = j; // Update index of new minimum
                }
            }

            // Swap the found minimum with the current starting position (i)
            int temp = scores[minIndex];
            scores[minIndex] = scores[i];
            scores[i] = temp;
        }

        System.out.println("--- After Selection Sort ---");
        printArray(scores);
    }

    public static void printArray(int[] arr) {
        for (int n : arr) {
            System.out.print(n + " ");
        }
        System.out.println();
    }
}

4. Insertion Sort

Definition: Insertion Sort builds the final sorted array one item at a time. It takes an element, compares it backward against the already sorted section, and shifts larger elements to the right until it finds the exact correct slot to "insert" the element (analogous to sorting playing cards in your hand).

Complete Runnable Example: Insertion Sort

InsertionSortMaster.java 
public class InsertionSortMaster {
    public static void main(String[] args) {
        int[] arr = {12, 11, 13, 5, 6};

        System.out.println("--- Before Insertion Sort ---");
        printArray(arr);

        for (int i = 1; i < arr.length; i++) {
            int key = arr[i]; // The element we are inserting
            int j = i - 1;

            // Shift elements of the sorted segment that are greater than key
            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j--;
            }

            // Insert the key into its correct position
            arr[j + 1] = key;
        }

        System.out.println("--- After Insertion Sort ---");
        printArray(arr);
    }

    public static void printArray(int[] arr) {
        for (int n : arr) {
            System.out.print(n + " ");
        }
        System.out.println();
    }
}

5. Quick Sort

Definition: Quick Sort is an efficient, recursive divide-and-conquer algorithm. It selects a benchmark element called a pivot, partitions the array so all smaller elements move to the left of the pivot and all larger elements move to the right, and then recursively repeats the process for both sub-arrays.

Complete Runnable Example: Quick Sort

QuickSortMaster.java 
public class QuickSortMaster {
    public static void main(String[] args) {
        int[] arr = {10, 7, 8, 9, 1, 5};

        System.out.println("--- Before Quick Sort ---");
        printArray(arr);

        quickSort(arr, 0, arr.length - 1);

        System.out.println("--- After Quick Sort ---");
        printArray(arr);
    }

    public static void quickSort(int[] arr, int low, int high) {
        if (low < high) {
            // Partition the array around a pivot index
            int pi = partition(arr, low, high);

            // Recursively sort elements before and after partition
            quickSort(arr, low, pi - 1);
            quickSort(arr, pi + 1, high);
        }
    }

    public static int partition(int[] arr, int low, int high) {
        int pivot = arr[high]; // Choose last element as pivot
        int i = (low - 1);     // Index of smaller element

        for (int j = low; j < high; j++) {
            if (arr[j] <= pivot) {
                i++;
                // Swap arr[i] and arr[j]
                int temp = arr[i];
                arr[i] = arr[j];
                arr[j] = temp;
            }
        }

        // Place pivot in its correct sorted position
        int temp = arr[i + 1];
        arr[i + 1] = arr[high];
        arr[high] = temp;

        return i + 1;
    }

    public static void printArray(int[] arr) {
        for (int n : arr) {
            System.out.print(n + " ");
        }
        System.out.println();
    }
}
