1 · The box word 1

Everything in this course is drawn with a few pictures. Here is the first one.

variableword 1
  • Definition: a named storage location in memory. It holds one value.
  • = (assignment) stores a new value there. The old value is replaced.
  • Picture it: the variable is a labeled box 📦 — the label is the name, the content is the value.
int age = 21;   // variable "age" now stores 21
age = 22;       // same variable, new value (21 is gone)

2 · Copying a value word 2

What does int b = a; actually do? For ints: a photocopy.

copying a primitiveint, double, boolean, char…
  • Definition: for primitive types, b = a stores a copy of the value in b.
  • Result: two variables, two independent values.
  • Picture it: a photocopy 📸 — changing the copy never changes the original.
int b = a;   // b gets its OWN copy of the number

3 · Objects and the arrow words 3, 4, 5

Three words, one real definition each — then one diagram that connects all three.

objectword 3
  • Definition: a value made of several pieces of data (fields) grouped together. A Student = a name + a grade.
  • Created with new.
  • Picture it: we draw an object as a card, one line per field.
new Student()   // builds ONE object: fields name and grade
the heapword 4
  • Definition: the region of the computer’s memory where Java stores every object.
  • An object is never stored inside a variable — always in the heap.
  • Picture it: variables are boxes on your desk; the heap is the warehouse where the cards are kept. 🏭
referenceword 5
  • Definition: the memory address of an object. A variable of a class type stores this address — not the object itself.
  • The dot . uses the address to reach the object, then reads or writes one field.
  • Picture it: we draw the address as an arrow from the box to the card.
Student s = new Student();   // s stores the new object's ADDRESS
s.name = "Amina";            // use that address, write field "name"

4 · Two arrows, one object words 6, 7

Section 2's photocopy experiment again — but with a card instead of a number. The answer flips.

copying a referenceword 6
  • Definition: for class types, b = a copies the address. No new object is created.
  • Result: two variables, ONE object — a change made through either name is seen through both. 👀
  • Picture it: two boxes, two arrows, one card.
Student b = a;   // copies the ADDRESS - still one student!
garbage collectorword 7 — the cleaner
  • Definition: the part of Java that automatically frees the memory of objects that no reference points to anymore.
  • You never delete objects yourself.
  • Picture it: a card no arrow can reach gets recycled. 🧹
a = null;   // if that was the LAST address, the object gets recycled

5 · null and the crash words 8, 9

What does an arrow box hold before it points anywhere? And what happens if you follow an arrow that isn't there?

nullword 8
  • Definition: the special value meaning “this variable stores no address”. No object is attached.
  • Printing null is safe — it just prints the word null.
  • Picture it: a box with no arrow coming out. 🚫
Student s = null;   // variable exists, address does not
System.out.println(s);   // prints: null   (safe)
NullPointerExceptionword 9 — the crash 💥
  • Definition: the runtime error thrown when the dot . is used on null — there is no address to follow, so no object to reach.
  • Prevention: if (s != null) before the dot.
  • Picture it: trying to follow an arrow that isn’t there.
s.name                       // CRASH - no object to reach
if (s != null) { s.name }    // safe - address checked first

6 · Rows of boxes words 10, 11

An array is just boxes in a row. There are two kinds of row — and now you know both kinds of box.

array of valuesword 10
  • Definition: a numbered row of variables of a primitive type. Each slot stores the value itself.
  • New int slots start at 0.
  • Picture it: value boxes in a row — the numbers live inside.
int[] points = new int[3];   // [0, 0, 0] - three zeros inside
array of objectsword 11
  • Definition: a numbered row of variables of a class type. Each slot stores an address — or null.
  • Creating the array creates no objects: every slot starts at null.
  • Picture it: arrow boxes in a row. 🅿️
String[] names = new String[3];   // [null, null, null] - no addresses yet
