What Is a Node in a Linked List?

Start with one box. Give it a value. Then connect it to another box.

1. A node is a small container

Instructor — say: “Imagine a train car. It carries something, and it can point to the next car. A node is like that car. It stores data and a reference to the next node.”
data10
next↗
one node
→null

Data = 10 is the value inside the node. next = null means the node does not point to another node yet. null is not another node.

Ask students: How many pieces of information does this node contain? And does null mean the number zero?
Two fields: data and next. null means “no node is referenced”; it is different from the number 0.

2. Build a linked list — one click at a time

Instructor — say: “We will build a list together. First we create a node containing 10. Then another containing 20. Finally, we make the first node point to the second.”

Click “Create node 10” to begin.

Ask students: After both nodes are created but before we connect them, is this already one linked chain?
No. There are two separate nodes. The connection appears only after we assign first.next = second;.

3. What does Java code look like?

Instructor — say: “The class is a blueprint for one node. The data field holds a number. The next field can hold a reference to another Node. Inside main, we create two Node objects and connect them.”
NodeDemo.java — complete runnable example 
public class NodeDemo {
    static class Node {
        int data;
        Node next;

        Node(int value) {
            data = value;
            next = null;
        }
    }

    public static void main(String[] args) {
        Node first = new Node(10);
        Node second = new Node(20);

        first.next = second;

        System.out.println(first.data);
        System.out.println(first.next.data);
        System.out.println(second.next);
    }
}

No import is required: this example uses only Java's built-in language features and System from java.lang.

Predict the output

10 20 null

first.data is 10; first.next refers to second, so first.next.data is 20; and second.next is still null.

Ask students: Why do we write first.next.data instead of first.data to get 20?
first.data reads the value in the first node (10). first.next follows the reference to the second node; adding .data reads 20 from that second node.

4. Let students change the data

Instructor — say: “Changing a node’s data does not automatically change which node comes next. Data and the next reference have different jobs.”
The first node contains 10 and points to the second node.
Ask students: If we set first.next = null, is the second object immediately deleted from memory?
No. The second variable still references that object. It can still be used. In general, Java objects become eligible for garbage collection only when no live references can reach them; collection does not happen immediately.

5. Two quick checks

Check 1: With Node a = new Node(5);, what is a.next in our class?
Check 2: What does a.next = b; do?

Wrap-up: three things to remember

1. Data
What the node stores.
2. Next
Which node comes after it.
3. Null
No next node is referenced.
