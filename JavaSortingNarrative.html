Mastering Java Array Sorting

How sorting algorithms think — before we look at the code.

Explain → ask → predict → visualize → connect to Java.

Teaching goal

Students should be able to predict the next move of each algorithm, not merely memorize loops.

What is a swap?

Sorting algorithms often need to exchange two values.

Explain the temporary variable

“If I overwrite one value too early, I lose it. So Java temporarily saves one value while the two positions exchange contents.”

arr[i] = arr[j];
arr[j] = temp;

Scene 3 • How expensive is the algorithm?

Big-O: how the work grows

O(n)

Double the data → roughly double the work.

O(n²)

Double the data → roughly four times the work.

O(n log n)

Much better scaling for large input.

Prediction

Which grows faster for large n?

Instructor wording

“Big-O is not a stopwatch. It tells us how the amount of work grows as the input size grows.”

Scene 4 • Bubble Sort

Bubble Sort: compare neighbors

Rule: compare adjacent values. If the left one is larger, swap them.

Story to tell

“The largest unsorted value moves step by step toward the far right. After a full pass, it is in its final position.”

Press “Next comparison.”

Scene 8 • Compare the ideas

Which algorithm thinks in which way?

AlgorithmCore ideaBestAverageWorstExtra spaceStable?
BubbleCompare neighborsO(n)*O(n²)O(n²)O(1)Yes
SelectionSelect minimumO(n²)O(n²)O(n²)O(1)No
InsertionInsert into sorted regionO(n)O(n²)O(n²)O(1)Yes
QuickPartition around pivotO(n log n)O(n log n)O(n²)Typically O(log n) stackNo

*Bubble Sort reaches O(n) in the best case with the no-swaps optimization.

Instructor summary

Bubble = neighbors. Selection = minimum. Insertion = sorted left side. Quick = pivot and divide.
