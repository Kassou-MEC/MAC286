2. Stack — Last In, First Out

10 minutes

A. Concept

Look at a stack of plates. When we add a plate, we place it on top. When we remove one, we also take it from the top. That's called LIFO — Last In, First Out.

If I add plates A, B, and C, in that order, which plate do I remove first?

Expected: C.

B. Core operations

OperationExplain it like this
push(x)Add an element to the top.
pop()Remove and return the top element.
peek()Look at the top without removing it.
isEmpty()Check if the stack has no elements.

C. Interactive classroom demonstration

Use the Stack Playground on the original website alongside this practice widget.

Stack Playground · Top → Bottom

Let's push 10, then 20, then 30. Before I click pop(), tell me: which number will disappear?
What if I click peek() instead? Does that number disappear?

Expected: No. Peek only looks.

D. Walk through the code

Java can implement a stack using ArrayDeque. We don't always have to build the data structure ourselves.
import java.util.ArrayDeque;
import java.util.Deque;

Deque<Integer> s = new ArrayDeque<>();
s.push(10);
s.push(20);
System.out.println(s.pop()); // 20
Next, look at the array-based stack example on the website. The variable top tracks the last occupied position. When we push, it increases; when we pop, it decreases.
If top == -1, what does it mean?

Expected: The stack is empty.

A practical application is checking balanced brackets. For { [ ( ) ] }, we must close the most recently opened bracket first. A stack remembers that order.
Why is ( [ ) ] incorrect?

Expected: The bracket closing order does not match the opening order.

Transition: Now imagine we need the opposite behavior: the first person arriving should be the first served.

3. Queue — First In, First Out

10 minutes

A. Concept

Imagine people waiting at a coffee shop. The person who arrived first should be served first. This is FIFO — First In, First Out. New elements join at the rear; elements leave from the front.
Ana arrives first, then John, then Maria. Who gets served first?

Expected: Ana.

B. Core operations

OperationMeaning
offer(x)Add an element at the rear.
poll()Remove and return the front element.
peek()Look at the front without removing it.
isEmpty()Check if the queue is empty.

C. Interactive classroom demonstration

Queue Playground · FRONT → REAR

Let's add Ana, John, and Maria. Look at the front. Who is there? If I click poll(), who leaves?
If a new person joins, do they join the front or the rear?

Expected: Rear.

D. Walk through the code

import java.util.ArrayDeque;
import java.util.Queue;

Queue<String> q = new ArrayDeque<>();
q.offer("Ana");
q.offer("John");
System.out.println(q.poll()); // Ana
In a circular-array queue, we can reuse empty spaces at the beginning of the array. The modulo operator % helps the index wrap around.
For an array of length 5, what is (4 + 1) % 5?

Expected: 0 — the index wraps back to the beginning.

The help desk example works similarly: requests enter a queue and are normally handled in arrival order.

Transition: But what if some tasks are more urgent than others? Let's look at Priority Queue.

4. Priority Queue — Most Important First

15 minutes

A. Concept

Imagine three patients: one has a headache, one has a broken arm, and one is having a heart attack. Should the hospital always serve the patient who arrived first? No. The most urgent case needs care first. A Priority Queue chooses the next element using a priority rule.
What is different from a regular Queue?

Expected: Priority, rather than only arrival order, determines which element is removed next.

B. Java operations

We still use offer(), poll(), and peek(). But with Java's default PriorityQueue<Integer>, the smallest number comes out first. Smallest numeric value means highest priority under this default ordering.

C. Interactive classroom demonstration

Min-Priority Queue · Values displayed in removal order

Display order is for teaching only; Java's internal heap array is not generally sorted.

Let's insert 40, then 10, then 30. Which value will poll() remove first?
Why does 10 leave before 40, even though 40 was inserted first?

Expected: The default Java min-priority queue removes the smallest value first.

D. Heap visualization

How can Java find the next smallest value efficiently? A Priority Queue is commonly implemented using a heap. In a min-heap, every parent is less than or equal to its children, so the smallest value is at the root.
The heap can be stored in an array. For a parent at index i, the left child is 2*i + 1 and the right child is 2*i + 2.
If the parent is at index 0, where are its two children?

Expected: Indices 1 and 2.

E. Walk through the code

import java.util.PriorityQueue;

PriorityQueue<Integer> pq = new PriorityQueue<>();
pq.offer(40);
pq.offer(10);
pq.offer(30);
System.out.println(pq.poll()); // 10
Important: Printing the whole PriorityQueue does not guarantee sorted output. Calling poll() repeatedly returns items in priority order.
We can reverse the rule with a comparator, so the largest number comes first.
import java.util.Comparator;
import java.util.PriorityQueue;

PriorityQueue<Integer> pq =
    new PriorityQueue<>(Comparator.reverseOrder());
If we insert 5, 20, and 10 with reverseOrder(), which leaves first?

Expected: 20.

When inserting into a min-heap, a new value may move upward: bubble up. When removing the root, a replacement may move downward: sink down. Show both using the original site's heap demo.

Transition: Now that we have explored all three, let's compare them.

5. Compare the three structures

5 minutes
The biggest difference is not that these structures store data — all of them do. The biggest difference is which element we remove next.
StructureRemoval ruleMain methods
StackNewest firstpush / pop / peek
QueueOldest firstoffer / poll / peek
Priority QueuePriority ruleoffer / poll / peek
With ArrayDeque, stack and queue operations are generally constant time. Heap-based priority queues typically take O(log n) time to insert or remove a value.
We insert 10, 30, 20 in that order. Which value is removed first from each structure?
Stack → 20; Queue → 10; default min-Priority Queue → 10.

7. Closing the lecture

2 minutes

Today we learned three different rules for processing data:

Stack: newest first. Queue: oldest first. Priority Queue: highest priority first.

Whenever you see a new problem, ask yourself: do I need the newest, the oldest, or the most important element first? This question will help you choose the right structure.
