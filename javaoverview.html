1Variables & data types

Boxes that hold your data

A variable is like a labeled box that stores one piece of data. In Java, every box must say what type of data it holds. The types you'll use most:

  • int — whole numbers (25, -3, 1000)
  • double — decimal numbers (19.99, 3.14)
  • char — one single character ('A'), in single quotes
  • boolean — true or false, nothing else
  • String — text ("Hello"), in double quotes. Capital S — String is a class, not a primitive.

The pattern is always the same: type name = value;

RememberJava checks types for you. If you try to put text into an int box, the program won't even compile — Java catches the mistake before you run anything. That's a feature, not an annoyance!

2Conditionals

Letting your program make decisions

Conditionals let your program choose between paths. There are three tools:

  • if / else — "if this is true, do A; otherwise do B"
  • if / else if / else — check several conditions in order; the first true one wins
  • switch — pick one option from a list, based on a value

3Loops

Repeating things without copy-pasting code

Loops repeat a block of code. Which one you pick depends on one question: do you know how many times to repeat?

  • for — when you know the count ("do this 5 times")
  • while — when you repeat as long as something is true
  • do-while — like while, but always runs at least once

Two helpers work inside any loop: continue skips just the current round, and break stops the whole loop.

4Methods

Naming a block of code so you can reuse it

A method is a mini-program with a name. Instead of writing the same code over and over, you write it once, give it a name, and call it whenever you need it. Three things to know about any method:

  • Parameters — the inputs it needs (inside the parentheses)
  • Return type — what it hands back. void means "nothing, I just do something."
  • Overloading — two methods can share a name if their parameters are different. Java picks the right one automatically.
RememberThe word static means the method belongs to the class itself — you can call it without creating an object. That's why main is static: it runs before any objects exist.

5Arrays & strings

Holding many values, and working with text

An array holds a fixed number of values of the same type, all under one name. You reach each value with an index — and counting starts at 0, so the first item is numbers[0]. This one fact prevents half of all beginner array bugs.

A String holds text and comes with handy built-in methods. One golden rule: to compare two strings, use .equals() — not ==.

6OOP basics

Classes and objects — data and behavior together

Object-Oriented Programming means bundling data (fields) and behavior (methods) into one unit called a class. A class is a blueprint; an object is one real thing built from that blueprint. From one BankAccount class you can create many separate accounts.

  • Fields — the variables inside the class (each object gets its own copies)
  • Constructor — a special method that runs when you write new, to set up the object
  • private — hides a field from outside code, so it can only change through your methods. This protection is called encapsulation.
  • this — means "my own field," used when a field and a parameter share a name

7Inheritance & polymorphism

Building new classes from existing ones

Inheritance lets a class receive everything from another class and add its own touches. class Car extends Vehicle means "a Car IS a Vehicle" — it gets all of Vehicle's fields and methods for free, and can override (replace) the ones it wants to do differently.

Polymorphism is the payoff: if you treat a Car and a Motorcycle both as Vehicles and call start(), each one automatically runs its own version. Same call, different behavior — Java picks the right one while the program runs.
