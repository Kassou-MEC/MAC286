MAC286 • Guided Classroom Story

Java Arrays, References & Memory

A narrative-first lecture designed for live teaching. Students follow one continuous story: a familiar variable → the need for arrays → references → indexed access → aliasing → null.

Teaching rhythm

Explain → Ask → Predict → Reveal → Connect to Java.

Scene 1 • Start with something familiar

We already know how to store one value.

Suppose I want to store one student's exam grade.

int grade = 90;

The variable grade stores one integer value.

Ask the class

What if I have 30 students?

Instructor narrative

“Java gives us a structure that can hold many values of the same type under one name. That structure is an array.”

Scene 2 • Replace many variables with one array

One name. Several values.

Instead of writing separate variables:

int grade2 = 85;
int grade3 = 100;
int grade4 = 75;

we can think of the grades as one collection:

Transition

“So far, an array looks like a row of boxes. But there is one important question: where is that row of boxes actually stored?”

“The variable scores does not contain all four integers. It contains a reference that Java uses to find the array object.”

Scene 5 • The surprise

Can two variables refer to the same array?

int[] a = {10, 20, 30};
int[] b = a;
a
b
→

20
30
Prediction

If b[0] = 99;, what will a[0] be?

Instructor explanation

“There are not two arrays here. There are two references to the same array. That is why a change through b is also visible through a.”

Scene 6 • What if the arrow points nowhere?

Understanding null

By now students understand that a reference normally leads to an object.

What if the reference leads to no object at all?
data
null
→
No array object

null means the reference currently refers to no object.

Ask students

Can Java evaluate data.length if data is null?

Instructor wording

“Java tries to follow the reference to find the array. But there is no array there. That is why a NullPointerException occurs.”

Important precision

A local variable declared only as int[] data; is not automatically usable as null. To demonstrate null explicitly, write:

int[] data = null;
Scene 7 • Put the whole story together

The mental model students should leave with

1
Declare a reference variable
2
new creates an array object
3
The variable stores a reference to it
Five questions students should now answer
  1. What is an array?
  2. Why do array indexes begin at 0?
  3. What does an array variable actually store?
  4. How can two variables modify the same array?
  5. What does null mean?
Closing statement

“When you read array code, do not just read the syntax. Draw the picture: variable → reference → array object → indexed elements. If you can see that picture in your mind, you can predict what the program will do.”

Exit question

If a and b both refer to the same array and b[2] changes, does a[2] see the new value?

Yes — because both variables reach the same array object.

Teaching note: the arrows in this lecture are conceptual references. They are not literal manipulable memory addresses.
